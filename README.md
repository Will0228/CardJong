# CardJong 仕様書

> ステータス: ドラフト（第2版）
> 最終更新: 2026-09-05

## 1. 概要

CardJong は、トランプを用いたゲームに麻雀の要素を取り入れた対戦ゲームである。
麻雀の「手牌を揃えて上がる」「鳴きで他家の捨て札を利用する」「ドラによる打点の変動」といった駆け引きを、トランプという馴染みのある道具立てで表現することを目指す。

## 2. コアコンセプト

- ベースはトランプゲーム、ルールの骨格は麻雀から借用する
- 麻雀を知らないプレイヤーでもトランプの延長として入れること
- 麻雀経験者には鳴き・ドラによる戦略性が伝わること
- 上がり形の判定は「色」レベル、鳴きの条件は「マーク」レベルとし、**鳴き＝テンポと引き換えに厳しい形を要求される**という非対称性を戦略の軸にする

## 3. 用語

| 用語 | 定義 |
|---|---|
| マーク（スート） | ♠ / ♥ / ♦ / ♣ の4種 |
| 色 | 赤（♥♦）／ 黒（♠♣）の2種 |
| ランク | A, 2, 3, ..., 10, J, Q, K の13種 |
| 刻子（コーツ） | 同じランクの組 |
| 順子（シュンツ） | 連続するランクの組 |
| 么九札（ヤオチュウ） | A・J・Q・K |
| 中張札（タンヤオ） | 2〜10 |

- A は順子の**最小（A-2-3…）としても最大（…Q-K-A）としても**使用できる（ポーカー準拠）
- ただし K-A-2 のような循環はしない

## 4. 使用カード

- **52枚 × 4デッキ = 208枚**（ジョーカーは使用しない）
- 同一カード（例: ♠7）は最大4枚存在する
- 同一の「ランク＋色」（例: 赤の7）は最大8枚存在する

## 5. プレイ人数

- 3人 または 4人でプレイ可能
- 3人時のルール差分は後回し（要検討項目を参照）

## 6. 手牌と上がり形

上がり形は **5 / 4 / 3 / 2** の4組で構成する。

| 構成単位 | 枚数 |
|---|---|
| 5枚組 | 5 |
| 4枚組 | 4 |
| 3枚組 | 3 |
| 雀頭（対子） | 2 |
| **合計** | **14** |

- 手牌は **13枚**。ツモまたはロンで14枚目を得た時点で上がり形を判定する
- 5枚組・4枚組・3枚組はそれぞれ**刻子または順子**のいずれか
- 雀頭は同一ランク2枚（色は一致していること）

### 6.1 組の成立条件

| 組 | 条件 |
|---|---|
| 刻子 | 同じランク。**同じ色であればマーク違いでも可**（例: ♥7 ♦7 ♥7 ♦7 ♦7） |
| 順子 | 連続するランク。**同じ色であればマーク違いでも可**（例: ♠5 ♣6 ♠7 ♣8） |
| 槓子 | **なし**（カンに相当する行為は存在しない） |

- 組をまたいだ色の一致は不要（5枚組が赤、4枚組が黒、でもよい）
- 同一の組の中に赤と黒が混在してはならない

## 7. 鳴き

他家の捨て札に対して鳴きを行える。鳴いた組は**公開**され、以後変更できない。

### 7.1 共通条件

- 鳴きで作れる組は **3枚組・4枚組のみ**（5枚組・雀頭は鳴けない）
- 鳴きには**同一マークで n-1 枚**が手札に必要（色一致では不可）
- 鳴いた瞬間、その組は同一マークで固定される
- 発声の優先順位は **ロン > ポン > チー**

> **設計上の帰結**: 同一カードは4枚しか存在しないため、同マーク5枚の刻子は物理的に成立しない。5枚組をポンできない仕様はこの制約と整合している。

### 7.2 ポン（刻子の鳴き）

| 作る組 | 手札に必要な札 |
|---|---|
| 3枚組 | 同一カード2枚（例: ♥Q ♥Q → ♥Q をポン） |
| 4枚組 | 同一カード3枚（例: ♠7 ♠7 ♠7 → ♠7 をポン） |

- 誰の捨て札からでもポンできる
- 4枚組のポンは存在する4枚すべてを1人が握る形になるため、極めて稀

### 7.3 チー（順子の鳴き）

| 作る組 | 手札に必要な札 |
|---|---|
| 3枚組 | 同一マークの連続2枚（例: ♠5 ♠7 → ♠6 をチー） |
| 4枚組 | 同一マークの連続3枚 |

- **上家（自分の直前の手番のプレイヤー）の捨て札からのみ**チーできる
- 5枚組のチーは不可

## 8. ゲーム進行

1. 親を決め、各プレイヤーに13枚配る
2. ドラ表示札を1枚めくる
3. 親から順に「ツモ → 捨てる」を繰り返す
4. 他家の捨て札に対してロン・ポン・チーを宣言できる
5. 上がり、または流局で1局が終了する

### 8.1 生き山

208枚をすべて引き切ると1人あたり約39回ツモとなり、麻雀（約18回）の倍以上になる。テンポを揃えるため**生き山の枚数を制限する**。

| 人数 | 配札 | ドラ表示 | 生き山 | 1人あたりツモ回数 |
|---|---|---|---|---|
| 4人 | 52枚 | 1枚 | 72枚 | 18回 |
| 3人 | 39枚 | 1枚 | 54枚 | 18回 |

- 残りのカードは使用しない（死に山）
- 生き山の枚数はバランス調整の対象

### 8.2 テンパイ・フリテン

- **テンパイ**: あと1枚で上がり形が完成する状態
- **フリテン**: 自分の上がり札のいずれかが自分の捨て札に含まれる場合、ロンできない（ツモは可）
- リーチ後は上がり札を見逃した時点でその局はロンできない

### 8.3 流局

- 生き山を引き切った時点で流局
- ノーテン罰符: 不聴者から聴牌者へ合計3000点（麻雀同様）
- 親がテンパイなら連荘

## 9. ドラ

- 生き山から1枚めくり、**ドラ表示札**とする
- ドラ表示札の**次のランクかつ同じ色**の札がドラ（例: 表示札が ♠7 → 黒の8 がドラ）
- K の次は A に戻る
- リーチで上がった場合、**裏ドラ**をめくる
- ドラは役ではない。ドラのみでは上がれない

> **補足**: ランクのみでドラを指定すると該当札が208枚中16枚（7.7%）となり、麻雀（2.9%）に比べ打点が過剰に膨らむ。「ランク＋色」指定なら8枚（3.8%）となり麻雀に近い。

## 10. 役一覧

### 10.1 構造上の注意

本作の上がり形は **5枚組・4枚組・3枚組が各1組ずつ**で、同じサイズの組が2つ以上並ばない。
そのため麻雀の**一盃口・三色同順・三色同刻・三暗刻**に相当する役は原理的に成立しない。
代わりに、以下2つを本作固有の軸として設計する。

- **5枚組をポーカーハンドとして評価する**（トランプ側の楽しさ）
- **5+4+3 = 12ランク連続**という本作固有の形（麻雀の一気通貫に相当）

### 10.2 状況役

| 役 | 翻 | 条件 |
|---|---|---|
| リーチ | 1 | 門前でテンパイを宣言 |
| ダブルリーチ | 2 | 第1ツモでリーチ |
| 一発 | 1 | リーチ後1巡以内に上がり |
| ツモ | 1 | 門前でツモ上がり |
| ハイテイ | 1 | 生き山最後の札でツモ上がり |
| ホウテイ | 1 | 最後の捨て札でロン |

### 10.3 手役

「喰い」は鳴きが入っている場合の翻数（喰い下がり）。

| 役 | 門前 | 喰い | 条件 |
|---|---|---|---|
| 断么九（タンヤオ） | 1 | 1 | A・J・Q・K を1枚も含まない（2〜10のみ） |
| 平和（ピンフ） | 1 | — | 5/4/3枚組がすべて順子（門前のみ） |
| 対々和（トイトイ） | 2 | 2 | 5/4/3枚組がすべて刻子 |
| 混全帯么九（チャンタ） | 2 | 1 | すべての組が A・J・Q・K のいずれかを含む |
| 純全帯么九（ジュンチャン） | 3 | 2 | すべての組が A または K を含む |
| 一色（ワンカラー） | 2 | 1 | 14枚すべてが同じ色 |
| 清一色（フラッシュ） | 4 | 3 | 14枚すべてが同じマーク |
| 一気通貫（トオシ） | 3 | 2 | 5/4/3枚組がすべて順子で、合わせて12ランク連続（A〜Q または 2〜K） |
| 入れ子（ネスト） | 2 | 1 | 5/4/3枚組がすべて順子で、開始ランクが同一（例: 7-8-9 / 7-8-9-10 / 7-8-9-10-J） |

### 10.4 ポーカー役（5枚組・4枚組の形に対する加符）

| 役 | 門前 | 喰い | 条件 |
|---|---|---|---|
| ファイブカード | 1 | 1 | 5枚組が刻子 |
| ストレートフラッシュ | 2 | 2 | 5枚組が同一マークの順子 |
| フォーカード | 2 | 2 | 4枚組が同一カード4枚 |
| フルハウス | 2 | 2 | 3枚組が刻子で、雀頭と合わせた5枚が同一マーク |

### 10.5 役満

| 役 | 条件 | 由来 |
|---|---|---|
| ロイヤルストレートフラッシュ | 5枚組が同一マークの 10-J-Q-K-A | ポーカー |
| 十三面（オールランク） | A〜K の全13ランクを1枚ずつ + 任意の1ランクの重複1枚 | 国士無双 |
| 大三元（フェイススリー） | J・Q・K の刻子を3組すべて揃える | 大三元 |
| 字一色（オールフェイス） | 14枚すべてが A・J・Q・K | 字一色 |
| 清老頭（オールターミナル） | 14枚すべてが A と K | 清老頭 |
| 四暗刻（オールコンシールド） | 門前で 5/4/3枚組がすべて刻子 | 四暗刻 |

> 十三面は「13ランク × 手牌14枚」という本作の構造にちょうど収まる形であり、国士無双の直訳として成立する。

### 10.6 未採用・要検討の役

- **七対子（セブンペア）**: 14枚を7つの対子で構成する別形。5枚組が揃わないときの救済になるが、4デッキ環境では対子が集まりやすく強すぎる懸念がある → バランス検証後に採否を決定

## 11. 得点

- **翻のみで計算する。符は使用しない**
- 4翻を満貫とする（麻雀より圧縮されたスケール）

### 11.4 その他

- 持ち点は各25000点スタート（要検討）
- ドラは翻数に加算する（1枚1翻）
- 3人時のツモ点配分は要検討

## 12. 親・連荘・局数

- 親は上がるか、流局時にテンパイしていれば**連荘**する
- 連荘するたびに本場が1つ増え、和了点に本場ごとに300点を加算する
- 局数は開始時に選択できる
  - **東風戦**: 東1局 〜 東4局
  - **半荘戦**: 東1局 〜 南4局

## 13. 要検討項目

### ルール
- 3人時のルール差分（配札枚数、生き山、上がり形の構成）
- 生き山の枚数バランス（現案: 1人18ツモ）
- 七対子相当の別形を採用するか
- 鳴きの回数制限を設けるか（鳴きすぎ対策）
- リーチ後の暗槓に相当する処理（カンがないため不要と思われるが要確認）
- 役なし上がりの扱い（形式テンパイの可否）

### 得点
- 持ち点の初期値と順位点（ウマ・オカ）
- 役の翻数バランス（特に清一色・一気通貫・役満級の頻度）
- ドラの枚数（表示札を2枚にするか）

### プロダクト
- 対象プラットフォーム
- 開発エンジン（Unity で進行中）
- オンライン対戦の有無（対応する場合は通信方式・同期方針）
- CPU対戦（AI）の実装方針
- UI/UX の方向性（13枚の手牌をどう見せるか）
